# 💻 Portfólio — Pedro Faber

Portfólio profissional desenvolvido para apresentar meus projetos, habilidades, formação acadêmica, certificações e experiência profissional na área de tecnologia.

O projeto utiliza uma estrutura dinâmica baseada em JSON, permitindo atualizar informações do portfólio sem a necessidade de alterar diretamente a estrutura HTML.

## ▶️ Executando o projeto

Clone o repositório:

```bash
git clone https://github.com/pedrohfaber-design/My-Portfolio
```

Acesse a pasta do projeto:

```bash
cd meu-portfolio
```

Como os dados são carregados através de `fetch()`, execute o projeto utilizando um servidor local.

Uma opção é utilizar a extensão **Live Server** no Visual Studio Code.
